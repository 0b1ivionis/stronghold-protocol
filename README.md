# Stronghold Protocol — Covenants & Operators

Live: **https://0b1ivionis.github.io/stronghold-protocol/**

A single-file, offline cheat sheet for **Arknights: Stronghold Protocol** (November 2026, "Thanks Celebration" Part 2).

Open `index.html` in any modern browser — no server, no network, no dependencies.

## Contents

- **26 covenants** — 10 core (炎 / 萨尔贡 / 维多利亚 / 谢拉格 / 阿戈尔 / 叙拉古 / 卡西米尔 / 乌萨斯 / 伊比利亚 / 莱塔尼亚) with activation rules and 6-operator bonuses, plus 16 extra covenants
- **143 operators** across tiers Ⅰ–Ⅵ, with portraits, covenant tags, traits (normal / elite values) and trigger tags
- **Search & filters** — by name, covenant, trait text, tier and trigger timing
- **Operator pages** — trait split into normal/elite, all covenant effects, quick facts, and recommended 6-operator lineups for every core covenant the operator belongs to
- **Covenant pages** — full effect text, activation details, and members grouped by tier
- **Deep links** — `#/op/<name>` and `#/cov/<name>` are shareable and survive refresh; in-app Back returns to the previous level

## Data

Operator and covenant data was compiled from the [PRTS wiki](https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录) (2026-11 season). Portraits are PRTS avatar images, downscaled and embedded as WebP so the page stays fully offline.
